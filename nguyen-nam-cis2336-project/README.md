# ArtConnect

ArtConnect is my individual project for CIS 2336 - Web Application Development at the University of Houston.

This website was created to provide a place where local artists can share their handmade artwork with the community. Visitors can browse different types of artwork, learn about upcoming events, and submit their own artwork through an online form.

## Website Pages

- Home
- Gallery
- Events
- Submit Artwork
- FAQ
- References

## Features

- Browse handmade artwork from local artists
- View upcoming art and craft events
- Submit artwork using an online form
- Read answers to frequently asked questions
- Responsive layout for different screen sizes
- Form validation using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
